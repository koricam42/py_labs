# Lab 1 - Geometry Calculator

**Author**: Jordan Mensah
**Date**: 9/19/26

## Description
A python-based program that runs in the terminal. It calculates the area and perimeter/circumference of both circles and rectangles.
This project will use custom modules, importing files with aliases to prevent naming issues, and logic with while loops

## Included Files

* `Lab1_koricam42-2.py`
* `circle.py`
* `rectangle.py`

## How to run
Run main file (Lab1_koricam42-2.py) in your terminal and follow the onscreen prompts
